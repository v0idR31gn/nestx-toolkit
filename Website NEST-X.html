Learn by doing

What each tool does — and why it matters.

These are not black boxes. Each tool explains the concept behind the result so you can connect the exercise to real security practice.

01

Port Scanner

Every open port is a potential doorway into a system. The scanner performs a standard TCP connect check against common ports and curated presets. For each result it shows the port number, the likely service, whether it is open or closed, and a short risk note.

Use it to learn how services are exposed, why legacy protocols such as Telnet and unencrypted FTP are risky, and how a small exposed surface makes a system easier to defend. It is ideal for localhost, a home lab, a CTF box or any system you have written permission to test.

  • Understand the difference between open, closed and filtered ports
  • Recognise high-risk services such as SMB, RDP, Redis and exposed databases
  • Practise reading a scan report without guessing what a port means
02

Password Strength Checker

Passwords usually fail for predictable reasons: they are too short, use only one character type, or follow a familiar pattern. The checker reviews length, lowercase and uppercase letters, numbers, symbols, common-password lists and simple sequences.

It turns those checks into a 0–100 score, an estimated entropy value and a checklist of exactly what needs improvement. Use it to explore why “P@ssw0rd!” is weaker than a longer passphrase, or to test a password policy before teaching it.

  • See how length and variety change the estimated strength
  • Get specific, actionable suggestions instead of a vague warning
  • Keep every test private — analysis happens on your computer
03

Random Password Generator

The generator uses Python's secrets module, which is designed for security-sensitive randomness rather than simulations. Choose a length from 8 to 64 characters, enable lowercase, uppercase, numbers and symbols, and optionally exclude characters that are easy to confuse.

Each password contains at least one character from every selected category, then the characters are shuffled. Use it to create unique credentials, generate examples for a lesson, or demonstrate why predictable passwords are a bad idea.

  • Cryptographically secure random generation
  • Clear entropy and strength feedback
  • Copy to clipboard instantly — no account or sync required
04

Metadata Extractor

Every photo, video and document carries hidden context: camera model, creation time, editing software and sometimes GPS coordinates. The extractor reads those fields with ExifTool and presents them in plain language, alongside the file's size, type and cryptographic hashes.

Hashes such as MD5, SHA-1 and SHA-256 act like a digital fingerprint. Comparing them is how investigators show that two files are identical or that a file has changed. The tool is read-only, and ExifTool is bundled, so the analysis works without an internet connection.

  • View EXIF, IPTC, XMP, GPS, maker notes and timestamps
  • Calculate MD5, SHA-1 and SHA-256 hashes for integrity checks
  • Save a JSON report for automation or a TXT report for reading
05

Phishing URL Detector

Phishing links often hide their real destination behind an IP address, an @ symbol, a look-alike subdomain or a shortened URL. The detector breaks a URL into its parts and runs a set of transparent heuristics against them, adding points for each warning sign it recognises.

The result is a 0–100 risk score with a verdict and a list of reasons, so you can see exactly why a link looks suspicious. Analysis is static: the URL is never opened, so nothing is loaded and no request is made. A low score is not proof of safety — it simply means the configured indicators did not fire.

  • Spot IP hosts, @ authority tricks, punycode and malformed hostnames
  • Detect URL shorteners, excessive subdomains and suspicious keywords
  • Learn the reasoning behind each score instead of trusting a black box

Common questions

Small project, clear answers.

Is Nest-X free to use?

Yes. Nest-X is a student project created for learning and is free to use for educational, ethical purposes.

Does the toolkit need an internet connection?

No. Passwords, files and analysis stay on your computer. The only network activity happens when you explicitly run a port scan against a host you are allowed to test.

Can I use the port scanner on any website or server?

No. Only scan systems you own or have written permission to test. Use localhost, your own home lab, a CTF environment, or an authorised target.

Do I need to install ExifTool separately?

No. exiftool.exe is bundled with the toolkit, so the metadata extractor works offline out of the box. If it is ever missing, the tool explains how to install ExifTool or add it to PATH.

Is the phishing URL detector safe to use?

Yes. It performs static analysis only — the URL is never opened or requested. The result is a heuristic warning, not a guarantee, so always use your own judgement before clicking a link.
