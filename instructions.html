Quick start guide

How to use Nest-X.

Download once, extract the package and open the launcher. Everything runs locally — there is no account to create and no cloud setup.

Download the toolkit

Go to the download section on the home page and click Download Nest-X Toolkit. You will receive one ZIP file named NestX_Toolkit.zip.

Extract the package

Unzip the file with Windows Explorer, 7-Zip, WinRAR or your system archive tool. Keep nestx_launcher.py, NESTX_Toolkit.py, exiftool.exe, the exiftool_files folder and the .bat launchers in the same folder.

Check Python

Nest-X needs Python 3.9 or newer. On Windows, Tkinter is included with the official Python installer. If Python is missing, install it from python.org and keep the “Add Python to PATH” option enabled.

Open the launcher

Double-click Run_NestX.bat for the desktop GUI, or open a terminal in the extracted folder and run:

python nestx_launcher.py

For the five-tool command-line menu, double-click run_cli.bat or run:

python NESTX_Toolkit.py

Choose a tool

Use the desktop sidebar to switch between the core tools, or pick an option in the command-line menu. Each tool has guided prompts, inline explanations and a clear result area.

Port Scanner Password Checker Password Generator Metadata Extractor Phishing URL Detector

Use it ethically

Only scan systems you own or have written permission to test. Never use the toolkit to access, damage or disrupt someone else's device or network. It is a learning aid, not an attack kit.

Troubleshooting

Launcher will not open?

Confirm that Python is available by running python --version. If Tkinter is missing on Linux, install your distribution's Tk package. On Windows, reinstalling Python with the default options restores Tkinter.

Metadata extractor

ExifTool was not found?

Keep exiftool.exe and the exiftool_files folder next to NESTX_Toolkit.py. Alternatively, install ExifTool and make sure it is in PATH, then run the tool again.

! Some antivirus products may flag a port scanner because of its network behaviour. The source code is plain Python in nestx_launcher.py and NESTX_Toolkit.py, and can be reviewed before running. Only use the tool on networks you are authorised to test.
